# Visual grounding for multimodal agents in XR

[← Back to profile](../README.md)

**Collaborators:** Lund University<br>
**Status:** Paper under review

## What it is
Voice-native multimodal LLMs can now take images as input, but in XR "what the user sees"
depends on the display: a VR headset, mixed-reality passthrough or a flat screen give the
agent very different views. This project studies how an agent can ground its answers in what
is actually on the user's display, so that it can refer to objects the user is looking at.

## Questions we look at
- How should visual context be captured and sent to a multimodal agent in XR?
- How does the display type change what the agent can see and how well it answers?
- What are the trade-offs between visual accuracy, latency and cost?
